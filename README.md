OMMY-FOOD

## Overview

This is a full-stack web application developed using HTML, CSS, Vanilla JavaScript, PHP, and MySQL. The project was built to practice full-stack web development by creating a complete application with a responsive frontend, server-side logic, and a relational database.

## Features

* User authentication (Login/Register) for admin only
* Responsive user interface
* CRUD operations (Create, Read, Update, Delete)
* PHP backend
* MySQL database
* Client-side validation using JavaScript
* Secure database communication
* Responsive design using HTML5 and CSS3

## Technologies Used

### Frontend

* HTML5
* CSS3
* Vanilla JavaScript (ES6)
  

### Backend

* PHP
